# Free Trim Sheet Tools

TrimSheetFast has two browser tools that do not require an account. They prepare a layout and a map pack. They are not the paid AI generator.

- Planner: https://trimsheetfast.com/tools/free-trimsheet-planner
- Builder: https://trimsheetfast.com/tools/free-trimsheet-builder
- Tools hub: https://trimsheetfast.com/tools

## Planner

Use the planner to decide the cuts before you spend a generation.

- Draw guide lines and color markers.
- Preview the layout on a 3D plane.
- Download a PNG of that layout.
- No signup.

Bring a layout you like into the generator when you want each color filled from a prompt. The paid editor is where style, quality level, and AI generation live. See [Getting started](getting-started.md).

## Builder

Use the builder when you already know what should be in each region and you want to assemble the maps yourself.

- Fill regions with Base Color, Normal, Roughness, Metallic, Ambient Occlusion, and Height.
- Export a 4096px atlas pack from the browser.
- No signup.

The About page describes this as an in-browser assembly step. It is not a promise that the builder runs the same generation as a paid plan. Commercial use of AI-generated maps is a paid-plan license. Read the Terms before you ship client work: https://trimsheetfast.com/terms

## Other free 3D tools

The tools hub also lists a browser 3D viewer, a model inspector, and a format converter, including format-specific pages. Those tools open or inspect mesh files locally in the browser. They do not build the trim sheet. A trim sheet still has to be laid out in the planner or the editor, and the meshes still have to be UV'd in your DCC.

## What to use when

| You need | Use |
| --- | --- |
| A layout PNG and a look at the cuts | Planner |
| A 4K pack you fill yourself | Builder |
| An AI-filled atlas from prompts and a style preset | The trim sheet editor, on a plan |
| To know whether a mesh is one material and one UV set | Your DCC, or the free inspector if you only need a quick look |
